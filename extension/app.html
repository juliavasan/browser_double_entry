Create Accounts and their Contacts in bulk

Load one file of Accounts and Contacts, and Bulk Entry fills in and saves Salesforce's own New Account and New Contact forms for you, one record at a time. It works in the Salesforce session you're already logged in to, and links each Contact to its Account automatically.

File format

A list of Accounts. Each Account can have children: its Contacts. Field names are Salesforce API names, as shown in Setup → Object Manager → Fields & Relationships.

{
  "records": [
    {
      "system": "salesforce",
      "object": "Account",
      "fields": { "Name": "Northwind Logistics", "Phone": "+1 312 555 0100" },
      "children": [
        { "object": "Contact",
          "fields": { "FirstName": "Maria", "LastName": "Gonzalez", "Email": "maria@northwind.example.com" } }
      ]
    }
  ]
}

Supported now: text fields such as Name, AccountNumber, Site, Phone, Website on Accounts, and FirstName, LastName, Email, Phone, Title on Contacts.
