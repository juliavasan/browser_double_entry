Create Accounts and their Contacts in bulk

List your Accounts and their Contacts in a spreadsheet, and Bulk Entry fills in and saves Salesforce's own New Account and New Contact forms for you, one record at a time. It works in the Salesforce session you're already logged in to, and links each Contact to its Account automatically.

  • One row per Contact. Account columns come first, then Contact columns.
  • Leave the Account cells empty to add more Contacts to the Account above.
  • Column names are the object and the Salesforce field name: Account.Name, Contact.Email.
Which fields can I use?

Account: Name (required), AccountNumber, Site, Phone, Website
Contact: LastName (required), FirstName, Email, Phone, Title

Other text fields usually work too: use the field name from Setup → Object Manager → Fields & Relationships. Dropdown, lookup and date fields aren't supported yet.

Using JSON instead?

Each Account lists its Contacts under children:

{
  "records": [
    {
      "system": "salesforce",
      "object": "Account",
      "fields": { "Name": "Northwind Logistics", "Phone": "+1 312 555 0100" },
      "children": [
        { "object": "Contact", "fields": { "FirstName": "Maria", "LastName": "Gonzalez" } }
      ]
    }
  ]
}
